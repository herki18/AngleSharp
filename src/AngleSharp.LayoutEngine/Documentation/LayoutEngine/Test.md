### User Story 1: Print File Modal & Toolbar Button Integration

**Title:**  
Print File Modal & Toolbar Button Integration

**Description:**  
_As a user, I want to print a file directly from the chat interface so that I can quickly obtain a hard copy and track the progress of the print operation. When I click the Print button on the toolbar, a modal should appear to confirm the print action, show progress details, and indicate file retrieval status._

**Acceptance Criteria:**

- **Toolbar Integration:**
    
    - The existing delivery toolbar is extended with a new **Print** button.
    - The button’s design must be consistent with the toolbar’s current style and follow the look image provided.
- **Modal Behavior:**
    
    - Clicking the Print button opens a modal dialog.
    - The modal provides clear indications of print progress, status messages, and any error or confirmation notifications.
    - The modal design follows the ABE guidelines, and the visual style should be aligned with the Figma designs.
- **Design Requirements:**
    
    - Use the provided look image (see below) as a visual reference.
    - Follow the Figma design files for detailed design guidelines and UI elements.

### User Story 2: Send Email Modal & Toolbar Button Integration

**Title:**  
Send File via Email Modal & Toolbar Button Integration

**Description:**  
_As a user, I want to send a file via email directly from the chat interface so that I can quickly share files with others without leaving the application. When I click the Email button on the toolbar, a modal should appear for me to input the recipient’s email address and track the sending process._

**Acceptance Criteria:**

- **Toolbar Integration:**
    
    - The existing delivery toolbar is extended with a new **Send Email** button.
    - The button’s design should match the overall style of the toolbar and adhere to the visual guidelines shown in the provided look image.
- **Modal Behavior:**
    
    - Clicking the Email button opens a modal dialog.
    - The modal includes:
        - An input field for the recipient’s email address.
        - A section to display file details (e.g., file name, size).
        - Visual feedback for the email sending progress (e.g., “Sending”, “Sent”, or error notifications).
    - Email address validation is performed to ensure proper formatting.
    - The modal design follows ABE guidelines and matches the styling provided in the Figma designs.
- **Design Requirements:**
    
    - Refer to the provided look image (see below) for visual styling.
    - Use the Figma design files for detailed UI elements, layout, and color schemes.
